About this project

This site exists as a test bed for Webstudio, a visual builder that integrates with GitHub. The framework underneath it is plain HTML and CSS, so anything built on top stays easy to read and version.

How the pieces fit together

Webstudio

The visual editor where pages get designed. It can push its output to GitHub, which is what this repo is here to receive.

GitHub

The source of truth. This repo holds the framework and whatever Webstudio adds, with every change tracked as a commit.

Vercel

Deploys the repo on every push to main, serving the static site straight from GitHub with no build step.
